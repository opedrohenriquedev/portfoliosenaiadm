# Portfólio SENAI – Técnico em Administração

Portfólio digital institucional com todos os conteúdos acadêmicos, situações de aprendizagem, materiais didáticos, apostilas em PDF e atividades dos 4 semestres do curso Técnico em Administração do SENAI.

## 🚀 Tecnologias
- HTML5 / CSS3 moderno (Variáveis CSS, Grid responsivo e Flexbox)
- JavaScript Vanilla ES6+ com roteamento hash (`#/semestre/1`, `#/materia/N1I-COMEC`)
- Bootstrap Icons & Google Fonts (Inter)
- Arquivos e documentos estáticos locais (100% autônomo, sem dependência do Google Drive)
- Pronto para deploy no **Vercel** e **GitHub Pages**

## 📂 Estrutura de Arquivos
- `index.html`: Aplicação SPA completa (Cards curriculares, abas por semestre, visualizador de PDF modal, lightbox e busca global Ctrl+K).
- `portfolio_data.js`: Base de dados estruturada com todas as 217 atividades, 15 componentes curriculares e links locais.
- `materiais/`: Pasta contendo todos os 200 documentos, apostilas PDF, apresentações e imagens baixados fisicamente da API do Classroom (~531 MB).
- `vercel.json`: Arquivo de configuração de rotas e arquivos estáticos para a Vercel.

## 🌐 Publicação na Vercel
1. Suba esta pasta para um repositório no seu **GitHub**.
2. Conecte sua conta na [Vercel](https://vercel.com) e importe o repositório.
3. Clique em **Deploy**. Todos os PDFs e materiais abrirão diretamente pelo domínio do seu portfólio!
